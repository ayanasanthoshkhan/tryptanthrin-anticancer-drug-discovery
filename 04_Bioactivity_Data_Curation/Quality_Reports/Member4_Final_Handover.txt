==================================================
4. CURATION PROCEDURE
==================================================

- Target identification using UniProt IDs.
- SMILES validation using RDKit.
- Canonical SMILES generation.
- Invalid SMILES removal.
- Positive numeric activity value filtering.
- Separate endpoint preparation.
- Primary and secondary target-name classification.
- Duplicate and conflicting measurement investigation.
- Quality report preparation.

==================================================
5. RECOMMENDATIONS FOR MEMBER 5 (AYANA)
==================================================

1. Begin with the primary datasets.
2. Keep IC50, Ki, Kd and EC50 separate.
3. Investigate conflicting measurements.
4. Do not blindly average duplicate measurements.
5. Consider compound-grouped train/test splitting
   using canonical SMILES.
6. Check target variants and assay differences.
7. Document every additional filtering decision.
8. Harmonize ChEMBL and BindingDB before combining.

==================================================
6. IMPORTANT LIMITATIONS
==================================================

Primary/secondary classification is based on target names.
It does not guarantee wild-type protein status or assay
comparability.

Some BindingDB records lack DOI information.
Assay method information is not consistently available.

Different activity endpoints should not be treated as
interchangeable.

Canonical SMILES do not resolve every salt, tautomer,
or stereochemistry-related difference.
