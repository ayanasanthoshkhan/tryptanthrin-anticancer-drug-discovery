# Member 4 – Bioactivity Data Curation

This folder contains the bioactivity data collected and curated
from ChEMBL and BindingDB for five selected anticancer targets.

## Targets
- IDO1
- TDO2
- VEGFR2
- EGFR
- PI3Kalpha

## Contents
- ChEMBL final ML datasets
- BindingDB primary datasets
- BindingDB secondary datasets
- Data quality reports
- Curation documentation
- Relevant notebooks and scripts
